# MirroLeap HQ Preview · Windows 预览构建（非稳定版）

本预览安装包使用独立应用 ID `com.slobys.mirroleap-hq-preview` 和产品名 `MirroLeap HQ Preview`。不覆盖 MirroLeap 正式安装、不参与正式版一键更新；原正式版可继续使用。

## v5.2.7：回归约 5 MB 的轻量级安装包（核心按需安装）

- **EXE/MSI 只包含 MirroLeap 桌面应用**，不再捆绑实验版 scrcpy 4.0、FFmpeg、SDL3、ADB 或 MSYS2 许可证目录。此前 5.2.6 的 EXE 约 48.5 MB，目标恢复到 5.2.3 约 4.9 MB 的体积等级。
- 普通 USB/Wi-Fi 投屏继续使用既有 scrcpy 引擎和软件内的常规引擎下载功能；**不安装 HQ，也不自动联网获取 HQ 核心**。
- **只有手动勾选「可选 2.35× 高清放大」时**，才从本版本 GitHub Release 获取单独的 `MirroLeap.HQ.Core_v1_x64.zip`，以应用内固定 SHA-256 完整验证，经过 ZIP 路径/解压容量限制、scrcpy 4.0 补丁标识验证后安装到个人 LocalAppData。中途下载失败不会将 HQ 选项误标为已开启，也不修改原来的 scrcpy。
- 下载会显示进度，安装一次后可重复使用；缓存独立于 EXE/MSI 和正式版程序，正常预览版签名升级保留此缓存（HQ v1 协议不变时无需每次重新下载）。
- 保留从 HQ Preview 5.2.6 开始的**隔离版签名更新**：使用 EXE 安装的用户可在软件内检查更新到下一 HQ Preview，正式 v5.1.4 不受影响。MSI 仍需手动更新，不与 NSIS 自动覆盖。
- 拆分只减少初始下载体积，不会神奇降低 HQ 模式实际运行时的 CPU 或内存使用；首次开启 HQ 仍需下载数十 MB 可选核心。

## 本轮实际提供的能力

### 高清采样与点击特效后续修复

- 在原始解码帧密度高于镜头输出像素时，仅对 Y 亮度平面执行 2×2 自适应子像素抗混叠，抑制文字细线的采样锯齿及闪烁，保持默认 2.35×；不会把原始清晰度不足的画面伪称为无损 4K。
- 悬浮栏的实时放大提示会显示当前真正成功提交到 Windows 的 **HQ 原始帧分辨率**，或清楚标注「Windows 桌面回退」及未启用实验 HQ 的状态；这是判断新路径有没有工作的依据。
- 点击特效的圆圈更大、更高对比度且有较长可见期；Windows CI 增加真实桌面合成像素测试，避免以仅成功调用 Win32 绘图 API 就宣称用户可见。
- **尚未完成 D3D11 GPU 高频渲染以及 1080P/2K Android 实机性能和画质对比。** 这仍是实验性 CPU/GDI 管线。

- 选择“可选 2.35× 高清放大”后，软件先按需安装已校验的独立 scrcpy v4.0 实验核心；下次启动 Windows 带边框投屏时使用该核心。
- 通过客户端的 `--version` 标识先验证补丁，随后仅向该已验证子进程传递随机 128-bit 映射 token；默认投屏仍使用原来的 scrcpy，不会分配 HQ 共享内存。
- 点击投屏悬浮工具栏的“实时放大”后，如果同一投屏会话产生有效解码帧，使用原始 YUV420P/NV12 源像素通过 CPU 双线性取样，提交到原生、鼠标穿透的圆形 GDI layered window。
- 默认 2.35 倍，鼠标滚轮扩大/缩小镜头直径，Ctrl + 滚轮调整倍率；原有 Windows 实时放大镜作为无法获取原始帧时的回退。
- 停止投屏、切换会话、解码器/音频重试时清理或复位帧发布状态，隔离不同设备的映射，不上传/保存投屏帧。

## v5.2.6：安装包瘦身与自动更新

- 过去的 5.2.4 / 5.2.5 预览版关闭了更新接口，也没有上传 NSIS minisign 签名；**无法仅通过服务器端修改让旧版自动更新**。第一次需要手动下载并安装本版。
- 本版开始，独立的 HQ Preview 通过预览标签 `hq-preview-v{版本}-run{构建号}` 查找新版，只接受有预览版 EXE、minisign 签名、SHA256 清单和最新清单 `latest.json` 的完整发行版本，不会自动转成普通 MirroLeap。
- **使用 NSIS EXE 安装**：从本版开始，未来 v5.2.7 及更高版本可以在应用内检查、弹窗确认后，下载并验证 Tauri 固定公钥签名再安装。安装器仍可能触发 Windows SmartScreen；minisign 签名不能替代 Authenticode CA 代码签名。
- **使用 MSI 安装**：暂不提供 NSIS 自动覆盖，以免造成双安装；仍需手动下载下一版 MSI。EXE、MSI 请二选一安装。
- 精简打包：不再整包复制官方 scrcpy 中和实验版 MSYS2 编译不兼容的 FFmpeg/SDL3 动态库，也不再附带整个 MSYS2 许可证目录。仅分发真实导入的 UCRT64 DLL 和对应许可证文件，完整保留已校验的 ADB 和 Android server。
- **自动更新需要一次可用的已签名发布和后续较新版本才能完成真实升级验收**；本版成功发布并不等于已在用户机器实测 v5.2.6 → v5.2.7。正式稳定版 v5.1.4 维持独立更新通道。

## 重要限制

**这还不是最终 D3D11 GPU 高清镜头。** GDI/CPU 预览版只验证“同一视频流的解码帧→内存→Windows 可见圆形窗口”的架构连接，不承诺达到 60fps、低延迟、无模糊、低 CPU 占用或完美颜色空间表现。当前 Windows CI 不连接真实 Android，2K/1080P 抖音视频、旋转、多 DPI、USB/Wi-Fi 场景仍待真机验收；受 DRM/硬解像素格式等限制，可能自动使用原有放大镜。

这是 **GitHub Actions 社区构建**。提供 SHA256 文件校验，但不代表已取得受信任的 Windows Authenticode 证书或 SmartScreen 信誉，Windows 可能弹出来源警告；请自行确认下载来源，勿关闭系统安全功能。

## 文件和安装

- **EXE**：NSIS 预览安装器，单独安装。
- **MSI**：独立预览 MSI，二选一安装，避免重复安装。
- **MirroLeap.HQ.Core_v1_x64.zip**：可选的实验 HQ 核心，不需要手动下载或解压；只有启用 HQ 时才会由软件校验并安装。
- **SHA256SUMS.txt**：两份轻量安装包与可选 HQ 核心的 SHA-256 校验。
- 正常使用时无需操作 HQ。只有想用高清放大时，在“GPU 解码与性能”勾选可选 HQ，等待首次核心下载/校验完成，再开始 Windows 带边框投屏，并从手机悬浮栏打开“实时放大”。
- 如发现性能回退或不稳定，关闭 HQ 选项、停止并重新启动投屏即可使用原生实时放大镜；正式版完全不受影响。

修改的 scrcpy 客户端基于 Genymobile/scrcpy v4.0 固定 commit `2322868e9e256eb5fce0b3d659ab2a409f29bae1`。原项目及 FFmpeg/SDL3/ADB 等许可证、源代码见其发行项目；MirroLeap 旁路新增文件依照仓库许可发布。修改后的源文件和重现流程：`hq/apply_scrcpy_v4.py`、`hq/scrcpy/*`。
