# MirroLeap

**轻盈投屏，专注当下**

基于 [scrcpy-gui](https://github.com/kil0bit-kb/scrcpy-gui) 二次开发的 Android 桌面投屏工具，使用 [scrcpy](https://github.com/Genymobile/scrcpy) 作为底层投屏引擎。

[下载最新版](https://github.com/slobys/MirroLeap/releases/latest) · [更新日志](https://github.com/slobys/MirroLeap/releases) · [安装问题指南](INSTALL_RECOVERY_CN.md)

</div>

## ✨ 功能特点

- **精简首页**：连接手机、选择分辨率、开关声音与真机边框、一键开始/停止投屏。
- **无线与 USB**：支持 USB 投屏、无线调试配对、设备记忆与重连。
- **手机外观与画笔**：竖屏/横屏真机边框、悬浮控制栏、标注画笔、橡皮擦、撤销、一键恢复。
- **悬浮栏防越界（v4.6.1）**：始终约束在手机投屏的可见上下范围、当前显示器工作区内，避开 Windows 任务栏；短横屏时自动切换双排按钮，避免画笔和关闭键被遮挡。
- **场景预设（v4.6.3）**：均衡、演示、流畅、高清四种一键预设，只改变下次投屏的分辨率、帧率与码率，保留设备、音频、录制和手机边框选项。
- **安全加固（v4.6.3）**：逐项更新有安全公告的前端依赖、添加持续审计；启动页/悬浮栏的 Tauri 权限与主窗口隔离，限制 CSP、报告文件名和终端命令，诊断数据默认排除设备地址与本地路径。
- **白屏修复（v4.6.4）**：恢复与 Windows WebView2 兼容的启动策略，增加不依赖 React 的故障提示，并在 CI 实际启动打包程序验证界面已渲染。v4.6.3 的 CSP 已临时回退，其他 IPC/导出/核心校验加固保留，详见 [安全说明](SECURITY_CN.md)。
- **界面防遮挡（v4.6.5）**：修复默认窗口和投屏运行后「开始/停止投屏」超出右侧卡片、覆盖「更多功能与快捷键」的问题。卡片高度按真实内容计算、底部保持独立可点，空间不足时整页滚动。Windows CI 使用 Edge 测量四种状态、四类窗口及 100%/150% 缩放的按钮边界，共 32 种场景。
- **MirroCapture 原始截图（v4.7.0）**：设置 → 工具与日志 → 保存原始截图。通过本地 ADB 保存当前选中手机的原始 PNG 到电脑下载目录，不需要先开启投屏；仅主动点击时截图，不上传云端。
- **MirroCapture 批注合成（v4.7.1）**：在投屏画面上圈画后，进入「设置 → 工具与日志」选择「保存含画笔截图」。软件获取该手机当前透明画笔图层、通过 ADB 截取原始手机画面，再按设备原始分辨率合成 PNG。支持颜色、撤销与橡皮擦透明效果；不包含手机边框、工具栏和电脑桌面。必须先启动投屏并留下至少一笔标记；切换横竖屏后应重新画笔再保存。保留「保存原始截图」独立按钮。
- **窗口稳定性 3.0 第一阶段（v4.7.2）**：减少不必要的 Windows 原生窗口层级调整。投屏边框与悬浮工具栏在位置、显示状态、窗口层级改变时立即同步，稳定时仅每 2 秒做一次健康确认；保留窗口最小化恢复、横竖屏、任务栏和多屏幕 DPI 校正。事件驱动 WinEventHook 与更大范围实机兼容性测试将在后续阶段继续推进。
- **MirroCapture 预览与复制（v5.0.0 集成，原阶段 v4.7.3）**：保存原始/含画笔截图后可直接在「设置 → 工具与日志」预览，点击复制将 PNG 写入 Windows 系统剪贴板。只允许主窗口读取「下载」目录里由 MirroCapture 生成的 PNG，图片不上传云端，切换设备自动清除旧预览。超大截图仍可正常保存，预览会给出独立提示；Windows 真机剪贴板粘贴仍需验收。
- **智能无线连接中心（v5.0.0 集成，原阶段 v4.8.0）**：复用原有的 USB 转无线、Android 11+ 配对、mDNS 发现和退避重连，在无线页增加连接阶段、成功/失败状态和自动诊断。发现同一 IP 的新端口可手动选择；区分配对端口与连接端口，并展示历史地址是已连接、离线还是等待授权。所有连接均只针对用户选择的地址，不扫描局域网。
- **统一版本更新入口**：每次启动后读取一次官方完整签名 Release；有新版本时首页和设置页右上角版本号亮起绿色小点，点击可查看更新说明和下载。NSIS 安装版仍经固定签名公钥核对后由用户点击升级，其他安装方式手动选择官方附件；原生下载先校验 SHA-256、保存到“下载”目录，不自动运行 EXE，不关闭 SmartScreen。软件升级与 scrcpy 引擎更新相互独立。
- **GPU 解码与性能检测（v5.0.0 集成，原阶段 v4.9.0）**：设置 → 投屏参数 →「GPU 解码与性能」会检测已安装的 scrcpy 版本与 --help 中的实际支持能力。scrcpy 5.0+ 才开放平台对应的 --hwdec 模式（Windows D3D11VA、Linux VA-API、macOS VideoToolbox）；旧版核心保持原启动方式。默认自动兼容，也可选纯软件或显式 GPU 解码。强制硬解失败后仅在日志识别到硬件解码错误时重试一次自动模式，可选输出真实 FPS 日志；不假称每台机器的显卡都可用，也不自动升级 scrcpy。
- **MirroPresent 专业演示工具（v5.0.0，悬浮控制栏）**：手机投屏右侧悬浮栏直接使用实时聚光灯和**定格截图**放大镜（需刷新快照、非实时视频），不会重复占用设置页；切换横竖屏丢弃旧快照，退出恢复手机触控。设置 → 工具与日志保留独立的 MirroCapture 截图工具。**原始／含画笔 PNG 不包含演示镜头。**
- **专业模式放在设置里**：摄像头、虚拟显示器、编码器、帧率、图形渲染器、录屏、快捷键、日志等功能按类别整理，仍可使用。
- **兼容旧配置**：延续之前 ScrcpyGUI 的配置存储与内部应用标识，不要求重新配对已授权设备。

## ✨ v5.0.11 · 连续置顶稳定性与启动更新弹窗（Windows 测试版）

- **连续置顶／取消修复**：在三个 HWND 之间同步 z-order 时，避免把普通窗口错误地排入别人的 topmost 层，导致第三次切换失败；增加保持分层的布局测试和单窗口 native tier 复核。不重启 scrcpy，不断开 ADB。
- **失败恢复更清楚**：Win32 修改失败时尝试一次仅针对当前窗口的原生层级刷新，显示具体是 scrcpy 视频、真机边框还是悬浮栏被拒绝，保留原来的投屏连接。
- **每次启动新版提醒**：发现高于当前版本的可信官方 Release 时自动弹出可关闭的更新窗口，并显示右上角绿色点；点击「稍后」仅关闭弹窗，本次仍可从版本号进入更新。只有用户点击安装才下载、验证签名并执行更新；没有新版时不弹窗。

## ✨ v5.0.10 · 悬浮栏真正实时置顶（Windows 实机测试版）

- **不重启、不掉线**：点击悬浮栏置顶或取消置顶时，原生 Windows 直接调整现有 scrcpy 视频、真机边框和悬浮栏的 HWND Z 顺序；彻底移除旧的“修改置顶失败就结束投屏并用新参数重启”的路径。
- **单击生效并确认**：只有三个窗口的原生置顶状态全部得到验证才返回成功，失败时尝试回滚、保持投屏，不再错误显示已置顶；跟随器与按钮切换串行，防止旧状态抢写。
- **视觉状态常驻**：置顶按钮由“置顶”变为绿色“已置顶”，再次单击立即取消；恢复、重新展开和前台切换时主动查询实时状态。此修复需要 Windows 真机跨应用置顶和取消置顶验收，v5.0.9 仍可用于回退。

## ✨ v5.0.9 · 旋转可靠性与软件更新入口（Windows 实机测试版）

- **旋转**：悬浮栏不再模拟 Windows 的 Alt+R；通过受限 ADB 请求 Android 窗口管理器临时切换到另一方向，依次确认 Android 截图与 scrcpy 视频画面变化，边框随后按真实宽高跟随。正常停止投屏时尝试恢复原来的自动旋转／锁定设置。**手机系统或应用仍可能拒绝方向切换，异常强制退出后也可能需要手动恢复自动旋转，请在真实设备上验收。**
- **下载**：在更新信息里点击官方 EXE／ZIP／MSI 改为应用受限下载、SHA-256 校验后存入 Windows“下载”文件夹；浏览器无法接管下载时也有明确反馈。仅 NSIS 安装版保留用户主动点击的签名验证在线安装；下载 EXE 不会自动执行。
- **位置**：设置中的重复 MirroPresent 操作卡片移除，聚光灯和放大镜在手机悬浮栏使用。软件更新卡片移至首页、设置页右上角可点击版本徽标；每次启动静默检查一次，发现新版显示绿色圆点，用户决定何时打开并升级。此版作为 **GitHub Pre-release 测试版**提供 Windows EXE、MSI、Portable ZIP 与 SHA-256 校验文件，稳定版不受影响。

## ✨ v5.0.8 · 真正的手机方向旋转、自动更新提醒与社区外链（测试候选）

这次根据 Windows/Android 实机截图修复 5 项体验问题。**旋转**不再使用只旋转电脑投屏外壳的 scrcpy Alt+右方向键，而是通过 Alt+R 请求 Android 应用切换横竖屏，并检测视频内容的实际方向变化；应用锁定方向时明确提示而不转动边框。**定格放大镜**遇到手机截图、SDL 视频与 WebView 边框在旋转时短暂不同步，有限等待并自动重试，仍严格拒绝异常图片并在失败时恢复触控。

**行为设置**恢复手机与连接／录制与保存的左右双列布局，窄窗口自动改为单列。软件现在**每次启动后静默检查一次**官方最新完整签名 Release，有新版本才弹出可关闭的升级提示；下载安装必须由用户主动点击。NSIS EXE 安装版使用内置 Tauri 公钥验签安装，Portable ZIP/MSI 则在系统默认浏览器打开官方文件页面；不绕过 Windows 安全防护。首页的 [YouTube 奶油频道](https://www.youtube.com/@naiyou) 和 [Telegram 奶油群组](https://t.me/naiyous) 采用 Rust 严格白名单调用系统默认浏览器，不再依赖 WebView2 无权限的新窗口打开操作。所有下载路径同样严格绑定官方仓库与版本。

## ✨ v5.0.7 · 在线升级与窗口稳定性修复（测试候选）

本版根据 v5.0.6 实机反馈，着重修复 **Windows 置顶被拒绝**、**D3D11 强制 GPU 解码回退后丢失真机边框**、在线更新只显示 v5.0.2 等问题。置顶优先尝试操作已确认的 SDL/外框窗口，当 Windows 不允许动态置顶时由主界面串行停止并重启 scrcpy，改由其原生 `--always-on-top` 参数完成；这个重启仍需实机确认。D3D11 或音频兼容回退创建了新的 scrcpy 进程后，现在会重建对应手机边框及悬浮栏并停止旧跟随器，防止留下无边框视频。

高级行为设置去除首页已有的“真机边框”、不再支持的“无边框”以及“记住窗口位置”重复入口；记住位置已移至投屏悬浮快捷面板，并与现有配置保存同步。首页顶部新增 YouTube [奶油频道](https://www.youtube.com/@naiyou) 和 Telegram [奶油群组](https://t.me/naiyous) 双入口。

软件内更新统一为**一个检查更新按钮**，查询官方最新完整 Release（包括预发布）。只有官方资产齐全且具有 minisign 签名文件才允许作为候选；对于 Windows NSIS EXE 安装版，用户再次点击安装后，Rust 会重新核对官方版本并以内置公钥验证下载的 NSIS 安装包，失败立即拒绝；ZIP/MSI 继续提供对应官方下载以避免无意覆盖。**旧 v5.0.6 客户端仍需要先手动安装此版才拥有新的单通道升级功能；跨版本真实安装流程需下一次新发布后再验证。**

## ✨ v5.0.6 · 悬浮演示与界面控制优化（测试候选）

本次迭代重点解决悬浮栏功能重复、聚光灯与放大镜圆圈固定尺寸、演示模式四角遮罩凸出，以及旋转与窗口置顶的反馈问题。悬浮栏新增独立 **MirroPresent 演示入口**，与画笔和快捷操作互斥；提供聚光灯、定格放大镜、刷新截图和退出演示，启用演示后可直接在手机画面上滚动鼠标滚轮改变圆圈大小，放大镜还能通过 Ctrl+滚轮调整倍率。放大镜快照失败将尝试自动恢复触控。演示遮罩增加与真机圆角一致的裁切，防止暗色遮罩覆盖金属边框。

移除了和「电源键」重叠的悬浮「息屏」操作，并移除设置页中重复的「全屏」「关闭屏幕」启动选项。旧版配置里的这两个隐藏参数在读取时会被清除，避免残留效果。悬浮「旋转」针对电脑上的投屏画面使用 Alt+右方向键；「窗口置顶」加强原生窗口状态确认及同步。但以上 Win32 操作仍需你的 Windows/Android 真机验收，不能只凭自动化构建认为已经完全修好。

## ✨ v5.0.5 · 实机反馈稳定性修复测试版

根据 v5.0.4 实机反馈，手机黑钛外框的 SVG 透明开孔与原生 GDI 视频遮罩同步提高四角圆角，减少边角画面露出；拖动期间原生视频、透明边框、悬浮栏使用同一个 Win32 DeferWindowPos 批量移动，同时暂停旧的 50ms 跟随器避免相互抢占造成卡顿。窗口置顶维护原生窗口层级并检查实际状态；全屏/旋转/粘贴由明确焦点的 SDL 真实扫描码发送（失败时提示），息屏改为 Android KEYCODE_SLEEP（部分机型可能暂停视频）。快捷九宫格增加发送中/指令已发送/失败反馈。软件更新现在分成“检查正式版”和“检查测试版”，仅正式 NSIS 安装版允许签名一键更新；测试版仅提供安全的官方手动下载链接。自动化回归不替代真实 Android 机型的进一步验证。

推荐直接下载 **Portable ZIP**，完整解压后双击 `Run-MirroLeap.cmd`（或 `mirroleap.exe`）。首次启动如提示缺少 scrcpy 引擎，可在软件里下载；已有引擎的用户可按 [免安装指引](INSTALL_RECOVERY_CN.md) 放置完整的 `scrcpy-bin`。

**基本操作：** 连接手机 → 授权 Android 调试 → 在首页选择设备 → 点击「开始投屏」。无线配对、码率/编码器和录屏等低频设置，从右上角的齿轮进入。

> 安全提示：发布文件提供 SHA-256 校验清单，但本项目目前尚未配置受信任的 Windows 代码签名证书，Windows SmartScreen 可能出现警告。哈希一致不等同于代码签名认证，请不要关闭 Windows 安全防护。

诊断报告与日志只保存到本地下载目录。导出内容会尽量过滤设备地址、私有路径和敏感选项，但分享前仍应自行检查。详见 [安全说明](SECURITY_CN.md)。
