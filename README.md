## ✨ 功能特点

- **精简首页**：连接手机、选择分辨率、开关声音与真机边框、一键开始/停止投屏。
- **无线与 USB**：支持 USB 投屏、无线调试配对、设备记忆与重连。
- **手机外观与画笔**：竖屏/横屏真机边框、悬浮控制栏、标注画笔、橡皮擦、撤销、一键恢复。
- **悬浮栏防越界（v4.6.1）**：始终约束在手机投屏的可见上下范围、当前显示器工作区内，避开 Windows 任务栏；短横屏时自动切换双排按钮，避免画笔和关闭键被遮挡。
- **精简画质选择**：仅保留一个分辨率下拉框（480P～4K），同步显示码率、帧率和编码格式，投屏运行中选择会自动重启视频流并恢复边框。
- **安全加固（v4.6.3）**：逐项更新有安全公告的前端依赖、添加持续审计；启动页/悬浮栏的 Tauri 权限与主窗口隔离，限制 CSP、报告文件名和终端命令，诊断数据默认排除设备地址与本地路径。
- **白屏修复（v4.6.4）**：恢复与 Windows WebView2 兼容的启动策略，增加不依赖 React 的故障提示，并在 CI 实际启动打包程序验证界面已渲染。v4.6.3 的 CSP 已临时回退，其他 IPC/导出/核心校验加固保留，详见 [安全说明](SECURITY_CN.md)。
- **界面防遮挡（v4.6.5）**：修复默认窗口和投屏运行后「开始/停止投屏」超出右侧卡片、覆盖「更多功能与快捷键」的问题。卡片高度按真实内容计算、底部保持独立可点，空间不足时整页滚动。Windows CI 使用 Edge 测量四种状态、四类窗口及 100%/150% 缩放的按钮边界，共 32 种场景。
- **MirroCapture 原始截图（v4.7.0）**：设置 → 工具与日志 → 保存原始截图。通过本地 ADB 保存当前选中手机的原始 PNG 到电脑下载目录，不需要先开启投屏；仅主动点击时截图，不上传云端。
- **MirroCapture 批注合成（v4.7.1）**：在投屏画面上圈画后，进入「设置 → 工具与日志」选择「保存含画笔截图」。软件获取该手机当前透明画笔图层、通过 ADB 截取原始手机画面，再按设备原始分辨率合成 PNG。支持颜色、撤销与橡皮擦透明效果；不包含手机边框、工具栏和电脑桌面。必须先启动投屏并留下至少一笔标记；切换横竖屏后应重新画笔再保存。保留「保存原始截图」独立按钮。
- **窗口稳定性 3.0 第一阶段（v4.7.2）**：减少不必要的 Windows 原生窗口层级调整。投屏边框与悬浮工具栏在位置、显示状态、窗口层级改变时立即同步，稳定时仅每 2 秒做一次健康确认；保留窗口最小化恢复、横竖屏、任务栏和多屏幕 DPI 校正。事件驱动 WinEventHook 与更大范围实机兼容性测试将在后续阶段继续推进。
- **MirroCapture 预览与复制（v5.0.0 集成，原阶段 v4.7.3）**：保存原始/含画笔截图后可直接在「设置 → 工具与日志」预览，点击复制将 PNG 写入 Windows 系统剪贴板。只允许主窗口读取「下载」目录里由 MirroCapture 生成的 PNG，图片不上传云端，切换设备自动清除旧预览。超大截图仍可正常保存，预览会给出独立提示；Windows 真机剪贴板粘贴仍需验收。
- **智能无线连接中心（v5.0.0 集成，原阶段 v4.8.0）**：复用原有的 USB 转无线、Android 11+ 配对、mDNS 发现和退避重连，在无线页增加连接阶段、成功/失败状态和自动诊断。发现同一 IP 的新端口可手动选择；区分配对端口与连接端口，并展示历史地址是已连接、离线还是等待授权。所有连接均只针对用户选择的地址，不扫描局域网。
- **统一版本更新入口**：每次启动后读取一次官方完整签名 Release；有新版本时首页和设置页右上角版本号亮起绿色小点，点击可查看更新说明和下载。NSIS 安装版仍经固定签名公钥核对后由用户点击升级，其他安装方式手动选择官方附件；原生下载先校验 SHA-256、保存到“下载”目录，不自动运行 EXE，不关闭 SmartScreen。软件升级与 scrcpy 引擎更新相互独立。
- **GPU 解码与性能检测（v5.0.0 集成，原阶段 v4.9.0）**：设置 → 投屏参数 →「GPU 解码与性能」会检测已安装的 scrcpy 版本与 --help 中的实际支持能力。scrcpy 5.0+ 才开放平台对应的 --hwdec 模式（Windows D3D11VA、Linux VA-API、macOS VideoToolbox）；旧版核心保持原启动方式。默认自动兼容，也可选纯软件或显式 GPU 解码。强制硬解失败后仅在日志识别到硬件解码错误时重试一次自动模式，可选输出真实 FPS 日志；不假称每台机器的显卡都可用，也不自动升级 scrcpy。
- **MirroPresent 专业演示工具（v5.0.0，悬浮控制栏）**：手机投屏右侧悬浮栏直接使用实时聚光灯和**定格截图**放大镜（需刷新快照、非实时视频），不会重复占用设置页；切换横竖屏丢弃旧快照，退出恢复手机触控。设置 → 工具与日志保留独立的 MirroCapture 截图工具。**原始／含画笔 PNG 不包含演示镜头。**
- **专业模式放在设置里**：摄像头、虚拟显示器、编码器、帧率、图形渲染器、录屏、快捷键、日志等功能按类别整理，仍可使用。
- **兼容旧配置**：延续之前 ScrcpyGUI 的配置存储与内部应用标识，不要求重新配对已授权设备。

## ✨ MirroLeap v5.3.3 · scrcpy 5.0.1 + D3D11 原始帧实验

**本版本为实验预览，需要真机验收。** 旧版「原始帧高清」一经勾选便切换到 scrcpy 4.0，导致 Windows D3D11VA 硬解参数无法继续使用、整段视频可能卡顿。新版将这个可选实验核心升级到固定的 scrcpy 5.0.1，并保留其 D3D11VA 视频解码、SDL 显示和原始帧接收。GPU 帧引用在解码线程仅做限频引用，后台线程最多每 125ms 进行一次 GPU→CPU 全帧读回；连续两次读回超过 45ms 则停用 HQ 通路并回退桌面放大镜，优先保护投屏流畅度。

这**仍不是最终 GPU 局部纹理放大（zero-copy）**，因为 GPU 帧读回和圆形 CPU/GDI 合成仍可能造成额外开销。只有真实安卓设备上的视频、FPS 与延迟测试通过后才能称为已解决卡顿。默认实时放大始终为 2.35 倍，不在设置里重复显示。普通用户不勾选实验原始帧就继续使用原有流畅引擎，正常升级无需下载实验核心。

### v5.3.2 · 固定倍率设置精简

默认实时放大倍率继续保持 **2.35 倍**，直接通过手机悬浮栏的「实时放大」使用；设置页面不再显示固定倍率勾选项。只保留独立的「原始帧高清（实验功能）」选项，默认关闭：普通实时放大沿用 scrcpy 5.x，实验源帧模式可能切换到 scrcpy 4.0 并影响流畅度。

### v5.3.1 · 流畅优先

**修复 v5.3.0 HQ 开启后整体投屏卡顿**：先前只勾选 HQ 就会无条件把普通 scrcpy 5.0.1 替换为实验 scrcpy 4.0，导致 Windows D3D11VA 硬解选项无法继续应用。新版将“2.35× 实时放大”设为**默认流畅模式（仍使用原来的 scrcpy 5.x）**，普通视频不会再因为曾勾选 HQ 就切换实验核心。默认取样来自已显示的电脑投屏像素，清晰度并不等于原始帧高清。

需要真正的原始解码帧局部取样时，可以进一步勾选**“实验性原始帧高清（切换 scrcpy 4.0，可能卡顿）”**，软件才会下载和启动 v2 核心。两种模式均保持默认 2.35× 倍率；实验模式可能降低整体流畅度、仍不等于 GPU D3D11 直采。旧用户已有的 hqLens=true 配置自动迁移到流畅模式，除非再次主动选择实验核心。

### v5.3.0 技术基础：按需帧与 CPU 限频

- **按需源帧**：仅在实时放大圆圈确实处于活动状态、鼠标位于手机画面内时，实验性 scrcpy 4.0 才复制 YUV 解码帧；放大关闭后立即停止大帧复制，避免勾选 HQ 就拖慢整个手机投屏。
- **CPU 渲染限频**：原始帧复制上限为 20 次/秒，CPU/GDI 圆形镜头根据绘制耗时独立限频，优先让 scrcpy 的正常视频解码/播放保持流畅。默认放大倍率仍是 2.35×；这不是最终的 D3D11 GPU 高清镜头。
- **实际解码诊断**：HQ 实验核心如果只报告 FPS、没有报告硬件/软件解码方式，界面会明确显示“核心未报告（无法确认 GPU）”，不再停留在“等待输出”。普通核心 scrcpy 5.0.1 的 D3D11 选项不能作为 HQ scrcpy 4.0 已开启 GPU 的证明。
- **可选 HQ v2 核心**：为确保旧版完整拷贝组件不会忽略按需开关，5.3.0 首次使用 HQ 时会重新下载一次独立 v2 核心（主安装包仍约 5 MB），之后可重复使用本机缓存。
- **FPS 提醒**：软件显示的 FPS 来自 scrcpy 真实日志。静止桌面可能只产生少量视频帧，单次 11 FPS 不能直接证明 Wi-Fi 或 GPU 卡顿；请用持续播放的视频，分别在 HQ 开/关状态比较。

## 🔬 MirroCreator 高清实时镜头 · 2.35 倍基线与下一阶段

用户确认 **2.35× 是希望保留的默认倍率**，不接受简单降低到 1.25× 来“假装修好了模糊”。因此在下一阶段独立开发分支中已把默认倍率恢复为 2.35×；滚轮改变圆圈大小、Ctrl＋滚轮改变倍率的设计不变。

**技术事实**：现有 Windows Magnification API 放大的是 scrcpy 已经缩小到投屏窗口上的桌面像素，即使手机本身输出 1080P/2K，源像素也可能已经在 SDL 显示阶段被丢弃。单独更换插值算法或提高对比度不能真正恢复文字、图标与视频的原始细节。

**高清路线**：复用当前唯一一条 scrcpy 视频流，在其 FFmpeg 解码输出的高分辨率 AVFrame 到达 SDL 缩放前增加受控帧旁路，再以 GPU 原始帧纹理做 2.35× 局部放大。只有通过 Windows GPU/USB/Wi-Fi 实机的流畅度和细节对比，才会称为“高清实时放大”；**目前仅为设计与基线准备，尚未交付该直接帧渲染功能**。

技术分阶段方案、窗口/触控/安全边界和验收指标详见 [《MirroCreator 高清实时放大实现方案》](MIRROCREATOR_HQ_RENDERING_CN.md)。v5.2.4 代码的 1.25× 是已被用户否定的过渡方案，不作为之后的默认目标。正式版仍保持 v5.1.4。

## 🧪 v5.2.4 · 视频清晰度优先与原生点击光圈（Windows 预发布测试版）

这次根据 v5.2.3 的实机反馈修复「打开实时放大后仍然刷到下一条抖音」「鼠标滚轮不改变镜头」「点击按钮是绿色却从未出现光圈」「放大画面模糊」等问题，默认不改变常规投屏模式。

- **实时放大独占本手机滚轮**：只有当用户主动开启实时放大、投屏在前台且指针位于本手机画面内时，Windows 原生鼠标钩子消费滚轮以调整镜头直径；按住 Ctrl＋滚轮调整内容倍率。这样滚轮不再同时传给抖音切换视频。离开手机窗口、关闭放大或窗口失焦后，普通滚动行为不受影响。不存在后台全局吞鼠标滚轮行为。
- **默认清晰度优先**：默认放大倍率下调至约 **1.25×**（最小 1.05×），减少放大已经渲染出来的低分辨率桌面像素时的模糊。要显示更多真实细节，建议让手机投屏窗口显示得更大，并使用合适的解码与 1080P/2K 设置；Windows 桌面放大无法凭空重建原始未显示的手机像素。
- **独立的原生点击光圈**：不再仅依赖可能被 SDL 遮住的 WebView 画布。新增 Windows 原生 BGRA 逐像素透明点击动画窗口，白色中心亮点加青绿色扩散双环，置顶但不会接管 Android 触控。点击画面时按实际显示结果计数，不把 WebView 的 ACK 当作原生光圈显示成功。两个通路的次数会分别显示在悬浮栏，便于排障。
- **可验证与清理**：点击特效仅用户主动开启时创建原生窗口，退出/断开/重载立即停止线程。Windows CI 专项新增原生光圈透明度与滚轮仅作用于手机画面内的回归测试。
- **预览版约束**：Windows 原生编译、布局、单测、WebView2 启动、安装包哈希与更新签名验收通过后才提供 v5.2.4 供真实电脑测试，不影响 v5.1.4 Latest 正式版或 main 分支。显卡驱动/受保护视频可能仍限制桌面放大效果。

## 🧪 v5.2.3 · 原生镜头滚轮缩放与可确认的点击光圈（Windows 预发布测试版）

根据实际视频教程反馈，进一步完善 Windows 原生 MirroCreator：

- **镜头范围与内容倍率分别可调**：开启「实时放大」并把鼠标放在手机画面内，直接滚动鼠标滚轮来增大或缩小放大圆圈；按住 **Ctrl＋滚轮** 单独增减内容的放大倍数。Windows 专属的被动低层鼠标滚轮侦听仅在实时放大启用期间安装，不吞鼠标滚轮消息，不更改 Android 权限；退出实时放大会及时卸载。
- **清晰度优先**：默认放大倍率从 2.35× 改为约 **1.55×**，可手动调至 1.15×–3.0×，降低常用场景下的像素颗粒感；圈圈直径可在屏幕宽度的约 28%–90% 间变化，始终留在手机画面内部。请注意放大现有桌面像素无法产生比实际屏幕更多的细节。
- **点击特效诊断**：启用时先在手机中央演示一次青绿色扩散双环；之后每次鼠标点击都等待 WebView 绘图 ACK，成功后悬浮栏显示「已识别 N 次鼠标点击」。可判断「鼠标检测没有收到」还是「画布层叠遮住」的问题；未收到 ACK 不虚报成功。
- **新回归门槛**：Windows CI 除实际编译、启动、打包签名以外，额外运行 Windows-only 原生镜头的圆圈边缘与滚轮倍率测试；前端交互及不同 DPI 布局检查继续保留。
- **独立预览**：不修改 v5.1.4 正式版或主分支，完整 CI 全部通过后才发布 v5.2.3 预览安装包。

## 🧪 v5.2.2 · Windows 原生视频实时放大和点击特效修复（预览版）

针对 YouTube 视频教程中的「视频放大卡帧」和「点击看不到光圈」实际反馈，重新处理底层机制，而不是继续提高 Android 截图轮询频率。

- **系统级实时放大**：主动开启后通过 Windows Magnification.dll 对正在更新的 scrcpy SDL 桌面画面进行实时放大，不再调用 ADB 截图轮询；桌面视频变化时，操作系统负责持续合成。圆形放大窗口不会超出手机可见区域，放大目标与鼠标位置保持一致。
- **鼠标穿透与退场清理**：原生放大窗口设为 click-through、no-activate，仅在当前投屏处于前台且鼠标位于视频内时显示；退出、最小化、失联或重载后销毁放大窗口及线程，不劫持 Android 点击。

## ✨ v5.0.3 · 快捷悬浮操作与签名在线更新

现在在 Windows 手机投屏右侧悬浮栏内可展开八个快捷操作（全屏、主页、返回、最近任务、电源、旋转、粘贴、息屏）；通过绑定当前投屏的原生窗口控制，保留画笔和一键恢复。软件更新增加明确的用户点击确认，针对 Windows **NSIS EXE 安装版**通过 Tauri 签名验证官方更新后重启，拒绝无签名或不匹配的安装包。免安装 Portable ZIP、MSI 安装版仍提供官方下载链接供手动升级，避免静默安装到错误目录。v5.0.2 旧版没有内置一键升级，首次迁移到 v5.0.3 需要手动安装；后续 NSIS 版本支持一键更新。Windows 可信 CA 代码签名仍未配置，请勿关闭 SmartScreen。

## ✨ v5.0.2 · 设置中心焕新

重新整理桌面设置中心的视觉与功能分组，四个专业页面不再堆成狭长的表单。投屏参数与 GPU 解码、参数概览并列呈现；行为选项拆成设备、窗口和录制卡片；主题、语言、缩放与 scrcpy 状态独立成组；演示、截图与日志以简短操作卡片展示，长说明可按需展开。兼容原有配置及五项 v5 功能，保留窄窗口滚动与响应式布局。

新版额外验证 Windows Edge / Chromium 在 100%、125%、150% 缩放和多种桌面宽度下的页面可达性。Windows 代码签名尚未配置，请保留系统安全防护。

## ✨ v5.0.1 · 更舒适的设置界面

本次维护更新保留 v5.0.0 的投屏、无线连接、截图预览、GPU 解码与 MirroPresent 功能，重点优化设置页的阅读体验：更大的文字与按钮、画质选项的响应式两列布局、输入增强独立分区、兼容选项可折叠，以及各设置分类统一的滚动和间距。新增 Windows Edge 的设置页面几何检查，在 100% / 125% / 150% 缩放与不同窗口尺寸下验证可操作性。

## 📥 下载与使用

适用于 **Windows 10/11 x64**，需要 WebView2 Runtime 与 Android 设备的 USB 调试/无线调试授权。

| 版本 | 文件名 | 适用场景 |
| --- | --- | --- |
| **免安装版（推荐）** | `MirroLeap_5.3.3_x64_Portable.zip` | 解压直接运行，绕开旧版卸载程序异常 |
| EXE 安装版 | `MirroLeap_5.3.3_x64-setup.exe` | 标准 Windows 安装 |
| MSI 安装版 | `MirroLeap_5.3.3_x64_en-US.msi` | 使用 Windows Installer 安装 |

**v5.3.3 继续用 MirroLeap 原有版本与签名更新频道，等待 Windows CI 验收通过后以正常的 v5.2.9 标签发布测试版。** [GitHub Releases](https://github.com/slobys/MirroLeap/releases) 中可选择具体版本附件；[Latest](https://github.com/slobys/MirroLeap/releases/latest) 暂保持 v5.1.4 正式版。不要把 Tags 页面自动生成的源码 ZIP 当作安装包。

推荐直接下载 **Portable ZIP**，完整解压后双击 `Run-MirroLeap.cmd`（或 `mirroleap.exe`）。首次启动如提示缺少 scrcpy 引擎，可在软件里下载；已有引擎的用户可按 [免安装指引](INSTALL_RECOVERY_CN.md) 放置完整的 `scrcpy-bin`。

**基本操作：** 连接手机 → 授权 Android 调试 → 在首页选择设备 → 点击「开始投屏」。无线配对、码率/编码器和录屏等低频设置，从右上角的齿轮进入。

> 安全提示：发布文件提供 SHA-256 校验清单，但本项目目前尚未配置受信任的 Windows 代码签名证书，Windows SmartScreen 可能出现警告。哈希一致不等同于代码签名认证，请不要关闭 Windows 安全防护。

诊断报告与日志只保存到本地下载目录。导出内容会尽量过滤设备地址、私有路径和敏感选项，但分享前仍应自行检查。详见 [安全说明](SECURITY_CN.md)。
